# Customer Shopping Behavior Analysis

## Project Overview
Analyzed 3,900 customer transactions to identify
shopping patterns, customer segments, spending
behavior, and product preferences.

## Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- PostgreSQL
- SQL
- Power BI

## Project Workflow

1. Data Loading and Exploration
2. Data Cleaning and Preprocessing using Python
3. Feature Engineering
4. PostgreSQL Database Integration
5. SQL Business Analysis
6. Interactive Power BI Dashboard

## Key Analysis
- Revenue by Gender
- High-Spending Discount Users
- Top 5 Products by Rating
- Shipping Type Comparison
- Subscribers vs Non-Subscribers
- Customer Segmentation
- Revenue by Age Group

## Dashboard
Interactive Power BI dashboard
showing customer shopping insights.

## Business Recommendations
- Improve subscription adoption
- Reward customer loyalty
- Optimize discount strategies
- Promote top-rated products
- Target high-revenue customer segments
